## Build safeguards

- `npm run build` delegates to the canonical cross-platform Node build.
- A normal `npm ci` runs that build through `prepare`, so a clean checkout recreates assets.
- Wrangler CLI has an explicit custom build command.
- Cloudflare Workers Builds should use build command `npm run build` and deploy command `npm run deploy`. Its dashboard configuration was not changed by this cleanup.
- The injected admin structure-script version is now based on its content hash, making repeated builds consistent.
- Ignore rules cover deployment output, local state, temporary exports, backups and generated diagnostics.
